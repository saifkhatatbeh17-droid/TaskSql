The files do not use GO. In SSMS, select and execute each numbered section separately, in order. Do not execute an entire file as a single batch. Select the correct database before creating a view, procedure, or trigger.

Creation and insertion sections are for a fresh database only. Both databases have already been created locally. Use the SELECT queries to view their existing data.
