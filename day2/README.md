# SQL Day 2
Database name: CourseHubDB_day2.
CourseHubDB_day2-MasterTask.sql contains the CourseHub practical task. Run it once on a server where this database does not exist.
CourseHubDB_day2-CheckResults.sql displays the completed task results and can be run repeatedly.
For the existing local database, only the database name was changed from CourseHubDB to CourseHubDB_day2. Do not rerun the creation script against it.
